# redeancora_compra

Integração Data7 com a API B2B da Rede Âncora — catálogo, carrinho, checkout e pedidos.

## Estrutura

- `src/` — código-fonte (`.bas`)
- `docs/` — documentação do projeto
- `data7.json` — configuração do projeto Data7

Após alterações no código, compile com **Ctrl+Shift+B**. O artefato `redeancora_compra.7Proj` é gerado localmente e não entra no repositório.
